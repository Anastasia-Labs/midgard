# Eval

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Define the prompt or skill variants, success rubric, trial count, and decision threshold before running candidates.

2. Prepare isolated environments with sanitized labels. Candidates see the organic task and their variant, not the grading rubric or rival identities.

3. Run comparable trials through the host adapter. Save artifacts and actual provider/model receipts separately from blinded outputs.

4. Obtain an independent blinded judgment against the rubric. Inspect every artifact and available scoped tool transcript yourself.

5. Compare outcomes, variance, chain-following evidence, and missing coverage. Recommend promotion only when the declared criterion holds.
