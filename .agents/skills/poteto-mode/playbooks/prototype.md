Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Name the empirical fork and the observable result that can settle it. Keep product preferences with the user.

2. Build the cheapest runnable sketch in an isolated scratch directory. Use arena only when distinct candidate shapes add evidence.

3. Run each sketch on the same scenario. Inspect the result rather than relying on candidate claims.

4. Choose with evidence, preserve useful artifacts, and remove owned scratch processes. Production integration is a separately verified increment.
