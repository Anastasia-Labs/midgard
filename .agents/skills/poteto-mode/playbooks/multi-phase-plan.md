# Multi-phase plan

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Ground the scope, invariants, current owners, and measurable completion predicate before decomposition.

2. Order small deliverable phases by dependency and risk. Each phase names its owner, files, observable behavior, exact verification, evidence destination, and predecessor.

3. Use repository-prescribed checks and relevant real-surface acceptance. Add a performance gate only when the change affects measured performance. Scale independent lanes to actual risk.

4. State commit/PR boundaries and the intended bases for a stack. Identify genuine user gates and capability gaps without adding an invented permission workflow.

5. Save a reviewable plan and validate it with the checks applicable to its content. Execution follows existing task authorization.
