# Hillclimb

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Pin a measurable target, workload, baseline SHA, trial method, and stop conditions. Read benchmark-checklist and open a decision trail.

2. For each iteration, state one falsifiable hypothesis and make an isolated change using the hillclimb role.

3. Run correctness gates and compare against the baseline with the declared sampling method. Reject inconclusive or regressing trials.

4. Keep and verify a demonstrated win as one reviewable unit. Remove only your unsuccessful experimental edits. Log every accepted or rejected hypothesis.

5. Stop at the target or the actual user-defined budget/stop condition. Report the metric trajectory, evidence, and unresolved limit.
