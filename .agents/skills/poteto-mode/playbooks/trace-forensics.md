# Trace forensics

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Identify the artifact format, capture conditions, and user question. Preserve the original artifact.

2. Parse and reduce the capture using a format-appropriate tool. Label missing timestamps, symbols, or workload context.

3. Trace the observed mechanism back to source. Distinguish what the capture proves from hypotheses needing live reproduction.

4. Return the diagnosis, source pointers, reduced evidence, and the next discriminating experiment.
