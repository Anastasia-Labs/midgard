# Session pickup

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Locate the specific task capsule, scoped chat, transcript, branch, or PR through the host adapter. Read the ending state and unresolved work first.

2. Inspect live git state, current head, dirty paths, owned processes, and PR/check state. Keep prior authorization and later user directives in the consolidated brief.

3. Reconcile claims against artifacts. Mark missing transcript or runtime evidence as a gap.

4. Continue the original objective from the first unverified step. Report a material scope correction, then resume useful work.
