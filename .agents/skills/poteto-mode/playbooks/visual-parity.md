# Visual parity

Read [the host adapter](../references/host-adapter.md) before host-dependent operations.

1. Identify both implementations and pin viewport, fonts, data, browser, and reference state.

2. Capture baseline images through an available browser automation tool. Compare the real renders and record differences.

3. Change one isolated styling or layout mechanism at a time. Check interactions and accessible behavior as well as pixels.

4. Recapture comparable states and inspect residual differences. Report images, comparison conditions, interactions checked, and gaps.
