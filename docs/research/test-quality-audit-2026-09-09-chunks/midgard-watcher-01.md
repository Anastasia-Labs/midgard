## Notes
- Shared infrastructure this chunk depends on: `tests/support/deployment-authority-fixture.ts` (single signed-manifest fixture; builds the manifest and verifies it through the real `verifyWatcherDeploymentIdentity`, so its `result` is a genuinely admitted identity - it caches and structuredClones a default and deep-freezes the cached copy, and `prover-funding.test.ts` L40-L66 tests that clone isolation itself), `tests/support/user-event-origin-fixture.ts`, `tests/support/state-queue-observation-fixture.ts`, `tests/support/replay-authority-fixtures.ts`, `tests/support/user-event-authority-scenarios.ts`, `tests/support/native-chain-sync-fixture.mjs` and the `tests/support/conway-block.hex` / `conway-reference-transactions.json` mainnet fixtures. Several verdicts rest on those fixtures being genuine rather than pre-baked; they were not audited in this chunk.
- Real production paths exercised (not mocked): a real child-process native chain-sync helper (native-recovery-boundary, fixture-finality-chronology, local-historical-capture), real TLS servers created with the system `openssl` binary (l1-adapter beforeAll - if openssl is absent the whole file fails closed, which is correct), real on-disk journals and SQLite stores (fault-proof-queue-journal, fault-proof-supervisor-finish, prover-funding-permit-mint), real CML/blake2b re-derivation from a real mainnet Conway block (native-block-admission, l1-adapter, local-historical-capture), and the real fault-proofs reconstruction/replay libraries (header-root-reconstruction, event-classification-verifier).
- Purely doubled boundaries: canonical-block-store uses an in-memory atomic cell for all persistence/crash claims; fault-proof-application stubs lucid, signer, reference-script resolution and workflow construction; local-historical-capture stubs global WebSocket/fetch as controlled Ogmios/Kupo servers (the decisions under test stay real).
- No file in this chunk is env-gated or skipped, and none is opt-in. The whole `demo/midgard-watcher` package `test` script runs in both `midgard-node-ci.yml` and `midgard-watcher-ci.yml`, so every file here is CI-enforced.
- Portability: `fault-proof-queue-journal`, `fault-proof-supervisor-finish` and `local-historical-capture` hardcode `mkdtemp("/var/tmp/...")` instead of `tmpdir()`; they will not run outside Linux/macOS.
- Discrimination gaps worth noting even in high-scoring files: `local-historical-capture` L1563, L808, L814, L838, L1260-L1275 use bare `rejects.toThrow()` / `toThrow()` with no message or code, so four distinct invalid creating-evidence conditions are only shown to fail somehow; `prover-funding-permit-mint` has no accepted-mint counterpart to its two refusals; `header-root-reconstruction`'s accept path compares reconstruction against a fixture whose roots were built with the same `buildCountedRoot` (the file documents this as an identity, and the discrimination comes from its per-field mutation matrix instead).
- Readability (section 10): `prover-funding-calculation.test.ts` L852-L1156 is one `it` with roughly forty assertions covering planning, restore, digest substitution and address-shape refusals; `fault-proof-application.test.ts` L292-L1320 is one `it` dominated by the nested-ternary roster table. Both would be easier to audit split into named cases.
- Duplicated coverage: the Conway block fixture and its transaction re-derivation are checked in `native-block-admission`, again in `l1-adapter` (cache replay), and again in `local-historical-capture`. Each adds a distinct boundary (admission; normalization session; two-query capture), so this is not redundant, but the fixture is a single point of dependence for three files.
