## Notes
- Template families in this chunk. (a) Seven `*-publication-fit` files (distinct-asset-accumulation-limit, missing-redeemer, unused-redeemer, unused-script-witness, protected-output-signer-missing, field-preimage-length-mismatch, observer-order-invalid) are one copied script: build the harness, apply the family's scripts against the real blueprint, publish each as a reference-script UTxO on the emulator, assert completeSignedBytes <= 15,872 (or 16,384). They exercise a real path and use an external limit, so they are worth keeping, but three of them (distinct-asset, missing-redeemer, observer-order-invalid) wrap the suite in `describe.runIf(hasFamily)` and vanish silently if the rebuilt blueprint stops carrying the family; the other four assert the titles are present and fail closed. Make them all fail closed.
- (b) Four `*fit-ledger` files. zero-input and input-set-uniqueness only re-hash a docs JSON body and compare it to the digest stored in that same file — no production module is even imported, so they cannot fail on any code change. mint-declared-asset-limit carries a 50-row hand-transcribed measurement table and compares it to the JSON it can itself rewrite under an env var. missing-signature is the least bad: its blueprintSha256 is derived from the real blueprint file, but its measurements are still read back out of the saved JSON. All four are the "hand-updated constant" churn the owner ruled against; the derivation-from-real-blueprint template lives in execution-source-script-decoding-fit-ledger.test.ts (not in this chunk).
- Shared helpers the chunk's verdicts depend on: `tests/support/emulator/*` (harness, measurement capture, reference-script publication), `tests/support/submit-init-emulator-shared.ts` (expectProofFit, realBlueprintPath), `tests/helpers/canonical-block-evidence-fixture.ts`, and `src/proof-fit/van-rossem-fit-ledger.ts`. I read van-rossem-fit-ledger.ts (it recomputes margins and the digest and throws on a non-positive margin, so the fit-ledger tests' "margin" assertions are checking its arithmetic over transcribed numbers, not measurements) and `expectCommittedFieldShapeOnchainRefusal` in support/committed-field-shape-emulator.ts (it does require /failed script execution/, so the adversarial file's `message.length > 0` assertions are backed by a real on-chain-refusal gate, not by any failure).
- Production paths exercised: real Lucid emulator with the real compiled blueprint in the lifecycle/publication/adversarial files (mint-authorization, committed-field-shape, min-fee, native-script-decoding, input-set-uniqueness, redeemer-canonicity, zero-input, withdrawal-mistag, all publication-fits, option-b-frontier); pure production functions with real CBOR/CML/MPF in network-id, scan-plan, witness-script-decoding, execution-source-script-decoding, missing-redeemer, funding-requirements, header-classifier, transition-trace-l1-evidence, cardano-capability-retained-da, script-sources-yields, cek-selection-facts, distinct-asset-recovery; mock/fake-port only in the workflow adapters (field-carriage-prerequisite, cursor-family-adapter, linear-family-adapter, da-hash-preimage, missing-native-script-tx-historical-script — the last stubs global fetch for the external-provider transport).
- Opt-in / conditional gating found: `describe.skipIf(!optionB)` in submit-init-emulator-option-b-reference-frontier (whole file, console.warn only); `describe.runIf(hasFamily)` in three publication-fit files; env-gated behaviour in mint-declared-asset-limit-fit-ledger (MIDGARD_UPDATE_..._LEDGER=1 rewrites the golden), withdrawal-mistag-installed-lifecycle (MIDGARD_WRITE_FIT_LEDGER=1 gates both the ledger write and the completed-case assertion), redeemer-canonicity (MIDGARD_PRINT_FIT=1 gates only console output), cardano-capability-retained-da (MIDGARD_BOUNDARY_CORPUS_JSON may substitute the corpus). None of these carry a re-enable condition in the skip itself.
