# Goal artifact templates (F05)

This directory contains exactly four worked artifacts required by
`GOAL_SPEC.md`, plus this policy file. Every worked artifact is concrete and
excluded from evidence aggregation. Copy its validated structure, then replace
the example-specific values before use. README.md is policy, not a fifth
worked artifact.

- `task-manifest-row.json` — a fully detailed (`detailStatus: DETAILED`) row for
  `docs/exec-plans/evidence/canonical-v1-goal-task-manifest-v1.json`.
- `necessity-artifact-template.md` — the §3.2 bounded-fallback necessity
  artifact.
- `structural-na-template.md` — an executable structural `N/A` claim (§9.1,
  Q49/F21).
- `subagent-assignment-brief.md` — the §5.1 assignment brief quoting a
  manifest row.

No other worked artifact filename is permitted in this directory. In
particular, the retained assignment filename is
`subagent-assignment-brief.md`.
