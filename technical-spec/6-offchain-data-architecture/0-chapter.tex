\chapter{Offchain data architecture}
\label{h:offchain-data-architecture}

Midgard operators only commit block headers to the L1 state queue.
They retain their actual blocks in the data availability layer through the required challenge and correction lifecycle. Pruning requires expiry and an authenticated terminal L1 outcome with the required finality depth; unknown or mismatched authority retains the data. Permanent archival service is a separate design expectation, not an automatic consequence of maturity.
