\section{Fraud proof tokens}
\label{h:fraud-proof-tokens}

Fraud proof tokens represent fraud proof computations that have successfully concluded.

\subsection{Minting policy}
\label{h:fraud-proof-tokens-minting-policy}

The \code{fraud\_proof} minting policy is statically parametrized on the \code{computation\_thread} minting policy.
Redeemers:

\begin{description}
    \item[Mint.] Mint a new fraud proof token whenever a fraud proof computation succeeds.
      Conditions:
        \begin{enumerate}
            \item The transaction must burn a \code{computation\_thread} token via the Success redeemer.
            \item The transaction must mint a \code{fraud\_proof} token with the same token name as the \code{computation\_thread} token.
            \item The terminal computation step must send the \code{fraud\_proof} token to the configured always-failing fraud-proof address, with inline \code{FraudProofDatum\{fraud\_prover\}}, no reference script, and no other non-ADA assets. This output check belongs to the terminal step helper, while the mint policy owns exact token replacement.
            \item The transaction must \emph{not} mint or burn any other tokens.
        \end{enumerate}
\end{description}

\subsection{Spending validator}
\label{h:fraud-proof-tokens-spending-validator}

The spending validator of \code{fraud\_proof} does \emph{not} allow its utxo to be spent.
Midgard fraud proofs last forever.
