\section{Off-chain Decoding}
\label{s:phase-two-decoding-off-chain}

Raw Flat-encoded UPLC is a script-authoring input, not the canonical V1 consensus script payload. The authoring implementation decodes the source with the pinned UPLC library, re-encodes it, and requires exact canonical bytes. It accepts UPLC version \code{1.1.0}. This UPLC language version is distinct from the Midgard protocol and envelope versions.

The authoring path converts the decoded term into a typed content-addressed graph and a canonical program envelope. The envelope binds the term root, reachable-node count, and material-byte count. Canonical node encodings cover constants, child sequences, and the enabled term alternatives. Graph verification checks authenticated node material and the declared bounds. The canonical credential script hash is derived from the versioned script carrying this envelope; the raw source-script hash is audit/remapping metadata and cannot substitute for that credential.

Operators and challengers consume the same canonical envelope and independently authenticated material. Forced submitters can publish the bounded material on L1 before placing the transaction order. Missing or malformed material must be distinguished from an executed script's rejecting verdict: it cannot be silently converted into a valid rejection of the user's transaction.

The earlier \code{BytesToTermStep} proposal described a separate trace of a bit-level Flat decoder. No such trace or \code{transformation\_proof} field is part of the current native witness wire. Current L1 disputes verify canonical material traversal and deterministic CEK transitions within the committed transaction-validation trace. Any future requirement to adjudicate the raw Flat-to-envelope authoring conversion needs its own specified commitment and proof boundary.
