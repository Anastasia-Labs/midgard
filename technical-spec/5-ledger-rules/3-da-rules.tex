\section{Data availability rules}
\label{h:data-availability-rules}

\subsection{Rule: Retained block payload matches the L1 header}

For each queued block header, the data availability committee retains a
\code{DaPayloadV1} value keyed by \code{header\_hash}.
Before signing an attestation, a committee node must verify:
\begin{enumerate}
    \item The stored bytes are an exact V1 identity or zstd envelope, and the
      authenticated inner payload CBOR is canonical with version~1.
    \item The embedded header hashes to the payload's \code{header\_hash}.
    \item The payload \code{header\_hash} equals the L1 state-queue header hash being attested.
    \item The embedded header is byte-for-byte the L1 header.
    \item Every member array is sorted by canonical key bytes and has no duplicate keys.
    \item Every final UTxO member contains canonical output-reference and
      full-output CBOR that folds to one exact
      \code{LedgerOutputCommitmentV1}; \code{utxos\_root} is recomputed with
      that descriptor as the MPT value, not with the full output bytes.
    \item The source roots, \code{utxos\_root},
      \code{transition\_trace\_root}, \code{event\_to\_step\_root}, and
      \code{validation\_traces\_root} recompute to the roots in the header.
    \item Every compact normal or forced transaction source has one
      same-key canonical full preimage and regenerates exactly from it.
    \item The declared counts equal the member-array counts and the header counts.
    \item \code{total\_event\_count} equals the sum of the per-source counts.
    \item \code{transition\_step\_count} equals \code{total\_event\_count}.
    \item The transition trace is dense, each trace key equals the opened \code{step\_index}, and each trace phase matches the event-key variant.
    \item Each event-to-step member points to an existing trace step whose event key and phase point back to that member.
\end{enumerate}

If any check fails, the committee node must not sign the DA attestation for that header.
This fail-closed rule is part of the fraud-proof soundness argument: a challenger can derive transition-trace witnesses only if the DA attestation covers the source members, event-to-step members, trace members, final UTxO members, and counts needed to reconstruct the committed roots.

\subsection{Rule: Normal transaction root projection}

The retained payload carries compact authenticated transaction-source values
separately from full Midgard-native transaction preimages used for replay and
proof construction. \code{transactions\_root} is computed from the compact
source values. DA validation regenerates each source from its same-key full
preimage before recomputing the root. L2 source membership and non-membership
proofs use those exact compact key/value bytes.
