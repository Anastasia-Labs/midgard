These modules build the transactions that manage the protocol reserve and pay out
withdrawals, enforced on-chain by the
[`reserve` and `payout` validators](/docs/onchain/consensus-validators).

## Modules

- **`reserve`**: manage the protocol reserve funds. Exports `ReserveSpendRedeemer`.
- **`payout`**: withdrawal payout minting and spending. Exports `PayoutDatum`,
  `PayoutSpendRedeemer`, and `PayoutMintRedeemer`.
- **`reserve-payout`** (`reserve-payout.ts` plus the `reserve-payout/` directory): the
  combined reserve-to-payout flow.
