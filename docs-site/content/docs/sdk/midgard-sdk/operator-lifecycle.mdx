---
title: "Operator Lifecycle"
description: "Building the transactions that register, activate, and retire operators, and the builder functions that produce them."
---

These modules build the transactions that move an operator through the
[operator directory](/docs/onchain/operator-directory), the on-chain linked list of
operators. The lifecycle moves an operator **registered → active → retired**,
inserting and removing it from the corresponding linked lists while preserving their
ordering.

## Builders

`operator-lifecycle.ts` exports the transaction builders directly, including:

- `buildRegisterOperatorTx`: register a new operator (into the registered list).
- `buildActivateOperatorTx`: promote a registered operator into the active set.
- `buildDeregisterRegisteredOperatorTx`: remove a registered operator.

plus datum helpers such as `encodeRegisteredOperatorDatumValue`. The
`active-operators`, `registered-operators`, and `retired-operators` modules cover the
per-list operations.

The `operator-lifecycle/` directory holds the exit and recovery side:

- `directory.ts`: `fetchOperatorDirectorySnapshotProgram` reads the three
  lists, the scheduler, and the hub oracle in one snapshot, with lookups such
  as `findNodeByKey`, `findAnchorNodeForKey`, and `schedulerCurrentOperator`.
- `status.ts`: `deriveOperatorStatus` answers where a key sits, whether it is
  a duplicate, whether it holds the shift, and when its bond unlocks;
  `assertOperatorNotInDirectory` is the registration skip check.
- `strike.ts`: `planInactivityTakeover` decides whether the scheduled operator
  can be struck now, and `buildStrikeInactiveOperatorTxProgram` builds the
  strike that hands the shift to the next operator.
- `exit.ts`: `deriveRetireOperatorWitnesses` and
  `buildUnsignedRetireOperatorTxProgram` build voluntary and forced
  retirements (`retiredOperatorBondTranche` gives the retired node's
  lovelace); `deriveRecoverOperatorBondWitnesses` and
  `buildUnsignedRecoverOperatorBondTxProgram` return the bond after the hold;
  `buildUnsignedSlashDuplicateOperatorTxProgram` removes a duplicate
  registration with a `DuplicateProof` from another list.

Forced retirement and duplicate slashing pay the penalty as the transaction
fee. The on-chain check is an equality, so those builders complete the
transaction without coin selection and balance it to the lovelace, returning
the remainder to the submitter as an explicit output instead of a change
output.
