These modules provide the shared protocol building blocks the other transaction
families rely on.

## Modules

- **`reference-scripts`**: publishing and referencing on-chain reference scripts.
- **`phas-membership`**: PHAS staking-reward-account membership registration
  (on-chain: [`phas`](/docs/onchain/phas-membership)).
- **`protocol-parameters`**: the protocol parameters used across transaction
  builders.
- **`ledger-state`** / **`ledger-constants`**, L2 ledger-state representation and
  shared constants.
- **`linked-list`**: the on-chain linked-list helper used by the
  [operator directory](/docs/onchain/operator-directory) and other list-backed state.
