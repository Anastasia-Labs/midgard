These modules cover post-merge user-event settlement and the operator/challenger sides of the
[proof protocol](/docs/spec/proof-protocol).

## `settlement`

Settlement-claim transactions for confirmed state. Key exported types include
`SettlementDatum`, `ResolutionClaim`, `EventType`, and `SettlementSpendRedeemer`. The
node command `resolve-event-settlement-proof` resolves existing settlement
membership evidence; it does not submit a resolution claim.

## `transition-trace`

Defines counted-root, event/step, and membership-proof encodings shared by node
construction and proof tooling. It binds intermediate ledger transitions inside
a block, not only the roots between blocks.

## `fraud-proof/`

The fraud-proof transaction builders, including the per-category flows that mirror the
on-chain [fraud-proof machines](/docs/onchain/fraud-proof-machines).
