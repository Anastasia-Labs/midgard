In addition to the Aiken validators, the repository includes a **Plutarch** library
at [`onchain/plutarch/`](https://github.com/Anastasia-Labs/midgard/tree/main/onchain/plutarch)
(`midgard-merkle`) that implements Merkle Patricia Forestry (MPF) proofs used by the
fraud-proof system.

## What it provides

- **`src/Validators/Membership.hs`**: on-chain membership verification against a
  Merkle commitment.
- **`src/Types/`**: the supporting types: `Blocks`, `Membership`,
  `StateCommitment`, `Constants`, `Classes`.

These proofs let a fraud proof demonstrate that a particular element is (or is not)
part of a committed block's state, without re-publishing the whole state on-chain.
