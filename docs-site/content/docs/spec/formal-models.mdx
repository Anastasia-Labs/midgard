---
title: "Formal Models (Lean4)"
description: "Status and acceptance criteria for the planned Lean 4 formalization of Midgard."
---

Lean 4 formalization is a **planned verification surface**. The repository does
not currently track Lean source files or machine-checked Midgard theorems under
`technical-spec/Lean4Midgard/`.

The intended work is to encode selected protocol structures and properties in a
proof assistant so key definitions and arguments can be machine-checked rather
than relying on prose alone.

<Callout type="warn" title="No current formal-verification claim">
Do not cite this page as evidence that Midgard is formally verified. A future
model must pin the protocol version, state its trusted base, link definitions to
executable encodings, and run in CI before it supports a conformance claim.
</Callout>
