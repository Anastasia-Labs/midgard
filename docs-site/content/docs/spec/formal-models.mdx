title: "Formal Models (Lean4)"
description: "The Lean4 formalization of parts of the Midgard protocol under technical-spec/Lean4Midgard."
---

Alongside the prose specification, the repository contains a
[`technical-spec/Lean4Midgard/`](https://github.com/Anastasia-Labs/midgard/tree/main/technical-spec/Lean4Midgard)
directory with **formal models** written in [Lean 4](https://leanprover.github.io/).

These models encode selected protocol structures and properties in a proof
assistant, so that key definitions and arguments can be machine-checked rather than
relying on prose alone.

<Callout type="info" title="Scope">
The formal models cover selected parts of the protocol, not the entire system. Treat
them as a rigorous complement to the prose spec and the executable code, not a
replacement for either.
</Callout>

See the `Lean4Midgard` sources for the exact definitions and lemmas that are
currently formalized.
