The Midgard normative protocol design target lives under
[`technical-spec/`](https://github.com/Anastasia-Labs/midgard/tree/main/technical-spec)
as a set of numbered LaTeX chapters that are assembled, in order, into a single
`midgard.pdf`. The build is driven by `latexmk` (packaged with Nix); see
[`technical-spec/README.md`](https://github.com/Anastasia-Labs/midgard/blob/main/technical-spec/README.md)
for the exact invocation.

<Callout type="warn" title="Design target is not conformance evidence">
For intended definitions, equations, and transaction diagrams, read the compiled
`midgard.pdf`. The document contains unfinished sections and future mechanisms.
Current implementation and launch claims must also be checked against
[Project Status](/docs/getting-started/status), the
[fault-proof audit](/docs/fault-proofs/overview), code, generated blueprints, and
acceptance evidence.
</Callout>

| Part | Chapter | Docs |

The [formal-models page](/docs/spec/formal-models) tracks a planned Lean 4
formalization. No Lean source files are currently tracked in the repository.
