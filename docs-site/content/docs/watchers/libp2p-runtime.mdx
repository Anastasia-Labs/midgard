The working DA committee node (`demo/da-committee-node`, package/bin
`midgard-watcher`) is a libp2p-based service. Its entry point `src/index.ts` wires
together several subsystems:

- **libp2p transport** (`src/da/libp2p/`), a gossipsub-based network for exchanging
  attestations, payloads, and proofs between committee peers. Uses
  `@libp2p/gossipsub`, `@chainsafe/libp2p-noise`, and yamux.
- **Watcher API server** (`src/api/`), the node's HTTP surface.
- **Peer coordination** (`src/peer/`), a signature coordinator/poller that collects
  peer signatures.
- **Signer & committee validation** (`src/signer.ts`), the DA signer and committee
  validation logic.
- **On-chain coordination** (`src/coordinator/`, `src/l1/`), an on-chain
  coordinator plus a submitter reconciler that reconciles committee state with L1.
- **Store** (`src/store/`), the watcher's persistent store (uses `pg`).
