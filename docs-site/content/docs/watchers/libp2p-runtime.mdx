The DA committee node (`demo/da-committee-node`) is a libp2p-based service. Its
entry point `src/index.ts` wires together several subsystems:

- **libp2p transport** (`src/da/libp2p/`), a gossipsub-based network for exchanging
  attestations, payloads, and proofs between committee peers. Uses
  `@libp2p/gossipsub`, `@chainsafe/libp2p-noise`, and yamux.
- **Process API server** (`src/api/`), HTTP health, readiness, and deployment-manifest surfaces;
  DA protocol data remains on libp2p.
- **Peer coordination** (`src/peer/`), a signature coordinator/poller that collects
  peer signatures.
- **Signer & committee validation** (`src/signer.ts`), the DA signer and committee
  validation logic.
- **On-chain coordination** (`src/coordinator/`, `src/l1/`), an on-chain
  coordinator plus a submitter reconciler that reconciles committee state with L1.
- **Store** (`src/store/`), the committee's persistent store, configured with either a file path or
  PostgreSQL credentials. The separate public reader requires PostgreSQL.

## Configuration inputs

The runtime reads its deployment and network identity from the environment:

- `MIDGARD_DEPLOYMENT_MANIFEST_PATH`: path to the deployment manifest JSON
  that pins the deployment the committee
  serves. This is the DA runtime manifest, distinct from the finalized contract
  deployment manifest; its exact schema is parsed by `da-transport.ts`.
- `MIDGARD_CONTRACT_DEPLOYMENT_INFO_PATH`: path to the contract deployment info
  produced at protocol init.
- `DA_LIBP2P_PRIVATE_KEY_SOURCE`: the node's libp2p identity key, given as a
  `seed:`, `hex:`, or `file:` source. Required in libp2p DA mode.

These are identity inputs, not a complete environment. Committee startup also
requires store configuration (`DA_COMMITTEE_DB_PATH` or `DA_COMMITTEE_DATABASE_URL`) and the
manifest-selected committee signer and provider settings validated by
`src/config.ts`. The public retained-DA reader has its own isolated environment
and [startup instructions](/docs/watchers/da-committee-node#dedicated-public-reader).
