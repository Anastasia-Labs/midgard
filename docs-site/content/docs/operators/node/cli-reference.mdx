`midgard-node` is a Commander CLI (`bin: midgard-node`). Run `midgard-node --help`
for the authoritative, version-specific list. The 70 commands below are grouped
by function.

<Callout type="info" title="The server">
`listen` is the long-running command that starts the HTTP API server and the
[background fibers](/docs/operators/node/background-fibers). See
[Server &amp; HTTP API](/docs/operators/node/server-http-api).
</Callout>
